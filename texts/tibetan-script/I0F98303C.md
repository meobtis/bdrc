# ཐུགས་རྗེ་ཆེན་པོ་གསང་བ་འདུས་པའི་ཆོས་སྐོར།

ཁཱཧལཱག སཞག་པ་ན་

ཕཊ༔ ཁ་ལ་རོན་ཁ་ལ་བོཤ་ཧཱུྃཕཊ༔ ཡཀྵ་ཀུན་ཁཾ་ཐབཊ༔ ཛྭ་ལ་ཛྭ་ལ་རཾ་ཧཱུྃ་ཕཊ༔ ཛུལ་ཨ་མུ་ཀཾ་ཛྲལ་ཨ་མུ་ཀཾ་ཧཱུྃ་ཕཊ༔ ཨམྲྀཏ་བ་ལིང་ཏ་རཀྟ་ཁཱ་ཧི༔

ལ་མཧཱུྃ༔ ཨི་དཾབ་ལི་ཁཱ་ཧི་ཁཱ་ཧི༔ ཨོཾ་བཛྲ་མ་ཧཱ་མ་ཏྲི་དུང་དུང་རི་ཛ༔ ཨི་དཾ་བ་ལི་ཁཱ་ཧི་ཁཱ་ཧི༔ ཧཱུྃ༔ དམ་ཅན་སྐྱེས་བུ་བཛྲ་ཐིག་ལེ་རྩལ༔

# འཚན་སཱབྷཱ་ཝ་ཨཱཏྨ་ཀོཉཧཾ༔ མ་ཊཱི་རུ་དྲ་ཛ ཨཱཀནརུ་དུ་ཛཾ ཁཏང་རུ་དྲཛ༔ ” ཞེས་དང་། ཨོཾ་བཛྲ་ཀཱི་ལི་ཀཱིལ་ཡ་མ་ཏཱཾ་རུ་དྲཔྲ་བྷན་ཙཀྲ་ཧཱུཾ་ཕཊ༔ ཙིཏྟ་པྲ་ཝེཤ་ཡ་ཤག་ཕའབ ན་

ཨོཾ་བཛྲམཧཱ་ཀྲོ་དྷཔདྨ་ཀྲོ་དྷིཤཱརི་བཛྲཀཱི་ལི་ཀཱི་ལ་ཡ་མ་ཧཱ་ཡཀྵ་ཀཱལ་

གནོད་བྱེད་དགྲ་བགེགས་འབྱུང་པོ་ཐམས་ཅད་མཱར་ཡ་ཧཱུྃ་ཧཱུྃ་ཕཊ༔
ལྕཔ་ཀམརཾ་རཾ་ཛལརོ་ཧཱུྃ་ཕཊ༔

ཞག་བཞིཞས་དྲུག་གི་བར་ཞག་གསུམ་ལ། མིག་བདུན་གཤམ་དུ། ཨ་ར་པ་ཙ་མི་ཏ་ཧྲི་ད་ཡ་སཱཧཱ༔ ཞེསབཏགས་པབཟླ། གྲོལཁར་ཞག་གཅིག་ཡ། དེ་གཉིསཾཀྱི་གཤམ་དུ། ཨོཾ་ཨཱཧཱུྃ་སྭཱ་ཧཱ༔ གྷོལཱ་ནཱཾ་དཾཏྟཾ༔

ཉྩལ་ཐམས་ཅད་ཁྱིམ༔ བཛྫཨཱ་ཡུ་ཤེ་རྒུ་ཨཱ༔ ཨོཾ་བཛྲ་ཨཱ་ཡུ་ཤེ་རྒྱུ་ཨཱ༔ སཱ་བཛྲ་ཨཱ་ཡེུ་ཧཱུྃ་ཨཱ༔ ཨཱ་བཛྫཨཱ་ཡུ་ཤེ་ཤུ་མཱ༔ སཱ་ཧཱུྃ་བཛྲ་ཨཱ་ཡུ་ཤེ་ཚུ་ མར་རེ་ལ་བརྒྱ་ཙམ་ནི

[ ༔ དཔྲལ་བར༔ ཨོབུདྡྷ་ཀཱ་ཡ་ཨ་བྷི་ཊཱིཉྩཨོ༔ རྣ་ལྟག་གཡས་སུ༔ སཱ་རབྷུཀཱ་ཡ་ཨ་བྷི་ཥིཉྩ་ཨཱུ༔ རྣ་ལྟག་གཡོན་དུ༔ ཨཱཝཔདྨ་ཀཱ་ཡ་ཨ་བྷི་ཥིཉྩ་ཨཱ༔ ལྷག་བར༔ ཧྭ་ཀརྨ་ཀཱ་ཡ་སཾ་བྷི་ཥིཉྩ་ཧཱ |

བཞི་ལ་རྒྱུན་སྤྱོད་ལུས་ཐུང་ནི་ལམཁྱེར་ལྟར་ ཙྪཱ བདག་ཉིད་སྒྱུ་མ་སོགས་བརྗོདོལ། ༀ བཛྲ་ཡཾཀཱ་ཧཱུྃ༔ བཛྲཀཱ་བཙིཏྟཾ༔ བཛྲ་ཧཱུྃ་ཧཱུྃ་ཧཱུྃ་ཧཱུྃ་ཕཊ༔ རང་ཉིད་དབང་ཆེན་རྟ་མགྲིན་མེ་དཔུང་འབར།

བར་ཤོག༔ ཨོཾ་མ་ཐམ་ཐ་སརྦ་ཏཾརཱི་ཀ་ག་ཏེ་ཧེ་ཏུན་ཧཱུྃ་ཕཊ༔

[ | ཨོ་ལཾ་སྤ་ར་ཎ༔ ཨཱལཾ་སྤུར་ཎ༔ ཧཱུྃ་ཁཾ་སྤ་ར་ཎ༔ སཱ་ལཾ་སྤ་ར་ཎ༔ ཧཱལཾ་སྤ་ར་ཎཿ ཁཾ་སྤ་ར་ཎཿ ཁཾ་སྤ་ར་ཎ༔ ༔་ལཾ་སྦར་5 , དུཏྟཱན་བཛྲ་ཨཱཧཱུཾ་སྤ་ར་ཎ་ཨཱ༔ཧཱུྃ་ཕཊ་སྭཱ་ཧཱ༔

མཉམ་འགྲོ་དོན་ཁྱོད་ཀྱིས་སྦྱོད་པར་ཤོག༔ ཡིག་བདུན་དང་༔ ཨོཾ་ཨཱ༔ཧཱུྃ་སྭཱ་ཧཱ༔ ཨོཾ་ལཱ་མཱ་པཱི་ཏི། བོ་དྷིཙིཏྟ་མ་ཧཱ་སུ་ཁ་ཛྙཱ་ན་དྷཱ་ཏུ་ཨཱ༔ བཛྲ་ཀཱ་ཡ་ཨ་བྷི་ཥིཉྩ་ཨཱ༔ ཝཱཀ་ཨ་བྷི་ཥིཉྩ་ཨཱ༔ ཙིཏྟ་
