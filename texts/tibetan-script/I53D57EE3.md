# སྨན་སྦྱོར་ལག་ལེན་ཕྱོགས་བསྒྲིགས།

ཏེ་མོ་སམྦྷ་ར་སམྦྷ་ར་ཧཱུཾ་ཁ་ཁ་ཁཱ་ཧི་ཁཱ་ཧི་ས་མ་ཡ་ན་ར་ ཀན་བཛྲ་ཧཱུྃ་ཕཊ།

ཨནྣཾཔྲ་ཏི་ཤ་སྭཱཧཱ། དེ་བཞིན་དུ་ ས་ཧཱུྃ པུཎེ། དྷུ་པེ། ཨ་ལོ་ཀེ གནྡྷེ། ནི་

བྷ་ར་ཛ་ཡ། ཏ་ཐཱ་ག་ཏ་ཡ། ཨ་ར་ཧ་ཏེ་ས་མྱག་ས་བུདྡྷཱ་ཡ། ཏདྱ་ཐཱ། ཨོཾ་བཱི་ཥ་

ས་བོན་གྱི་མཚན་པའི་སྟེང་དུ། ཧཱུྃ་ལཾ་མཾ་སཾ་ཏཾ་མི་སམ་མི་དང་། བ་གླང་དང་།

ཡང་ཟབ་སྔགས་ནི་འདི་ལྟ་སྟེ།། ཨོ་ཏིཿཧཱུྃ་ཁཾཕཊ༔བྷནདྷནཀུདན

[ བིཌཱུརྱ] ཡི་འོད་ལ་ཕྱག་འཚལ་ལོ།། ཨོ་བྷིཥ་ཛེབྷིཥ་ཛཿམ་ཧཱ་བྷིཥ་བློབྷི་ཥ་ཛུར་

སྤོས་དཀར་ཐལ་ཀ་རྡོ་རྗེ་སོ་མ་རཱ་ཛ༔ གེ་སེར་ན་ ནཱ་གུ་གེ་སཛྫཱཏྱཾ་པུཥྛ་ པུཥྛར/

དགུའི་སྔགས་བཏབ། ཨོ་ཐཾཏཾ་སྭཱཧཱ། གྷི་ཝང་ལ་ཨོ་བྷི་ན་བྲན་ན་སཱཧཱ། ཨ་རུ་
ལ་ཨོ་པྲ་ན་སཱཧཱ། གླ་རྩི་ལ་ཨོ་གྷ་དྷ་སཱཧཱ། ཤིང་ཀུན་ལ་ཨོ་པ་ཤ་མ་སྭཱཧཱ། གུ་གུལ་
ལ་ཨོ་ར་སཱཧཱ། ཤུ་དག་ལ་ཨོ་རུ་སྭཱཧཱ། མུ་ཟི་ལ་ཨོཾ་ཤ་སཱཧཱ། རྒྱ་སྣག་ལ་འདི་ལྟ་

[ བཻཌཱུརྱ་ཡི་འོད་ལ་ཕྱག་འཚལ་ལོ།། ཨོ་བྷི་ཥ་ཛེབྷི་ཥ་ཛེམཧཱ་བྷི་ཥ་ཛེརཱ་ཛཱ་ས་

[ ཁཎྜ ] ཤུབཟང་པོ་དྲུག ཅུ་གུར་ཎྞཾ ཡལི་ཀ སུགཙྩཾ། ཆུ་སེར་སྨན་གསུམ་གུལ་

གང་ལྕོགས་བཟླ། སྐབས་སུ ཨོཾ་ཨཱཿཧཱུྃ་སརྦ་པཉྩ་ཨ་མྲྀ་ཏ་ར་ས་ཡཱན་ཏན་ཛ་ཡ་
གུ་རྒྱུ་སིདྡྷི་ཧཱུཾ་ཧཱིཋ ཞེས་དང་། ཨོཾ་ཨཱཿཧཱུྃ་སརྦ་པཉྩ་ཨ་མྲྀ་ཏ་མཉྩ་ཤྲཱི་བྷ་བ་ལོ་ཀི་
ཏིཧཱུྃ་ཧིa ཞེས་འཇམ་དཔལ་བདུད་རྩིའི་སྔགས་དང་། ཨོཾ་ཨཱཿཧཱུྃ་སརྦ་པུཛྙཱ་
ཛྙཱ་ན་ཨཱ་ཡུ་ཏེ་ར་ས་ཡཱ་ན་ཨམྲྀ་ཏ་ཧཱུྃ་ཧི ཞེས་པ་གསུམ་ཀྱང་བརྒྱ་ཙམ་རེ་

བཛྲ་ཊཱ་ཀི་ནི། རཏྣ་ཊཱ་ཀི་ནི། པདྨ་ཊཱ་ཀི་ནི། ཀརྨ་ཊཱ་ཀི་ནི། ཨོཾ་ཨཱཿཧཱུྃ། མི་མང་

བསྟབས།༣ ཕཊ་ཕཊ་ཕཊ། ལན་ཆགས་ འབྲས་ཆན་བཤམས་ལ། ཕཊ།

བསྟབས།། ཕཊ་ཕཊ་ཕཊ་ ལན་ཆགས་འབྲས་ཆན་བཤམས་ལ།། ཕཊ་
