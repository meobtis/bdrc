# སྔ་འགྱུར་རྙིང་མའི་གླེགས་བམ་རིན་པོ་ཆེ།

་།ཡཱ ནཱ གྲ ར ཀོཥ ནཱ མ བི ཛ ཧཱ ལཾ།།

༄༅། །པ དཱ རྦ ར ཏྭཱ སྱ ཀོ ཥ ནཱ མ གུ རྒྱུ ནུ ཏ རཱ ཤུ ཀཱ ཀཾ བ ཛྲ ག རྦ སྱ སྦྲུ ན བེ རོ ཙ ན བི ཛ ཧཱ ལཾ།། །།

༄༅། །ཨུ པ དེ ཤ ར ཏྭཱ ཀོ ཥ ནཱ མ བི ཛ ཧཱ ལཾ།། ། །

༄༅། །ས རྦ ཛཱ དྷ རྨ རཱ ཛ མ ཧཱ བ བོ དྷ པྲ སཱ ར ཎ ཤཱི༔ བྷ དྲ སྱ བི མོཀྵ བི ཧ རཾ།། །།

༄༅། །ས རྦ ཛཱ དྷ རྨ རཱ ཛ མ ཧཱ བ བོ དྷ པྲ སཱ ར ཎ སྱ པྲ བ ཙ ནཾ ད རྣ ནཾ ཙུ ནྡ བི ཧ རཾ།། །།

༄༅། །མ ཧཱ ཡཱ ན ཨུ པ དེ ཤ ཤཱ སྱཱ ཙི ནཱ ར ཀོ ཥ ནཱ མ བི ཧ ར ཏི སྨ།། །།

༄༅། །རྒྱ་གར་སྐད་དུ། མ་ཧཱ་ཡཱ་ན་ཨུ་པ་དེ་ཤ་ཤཱསུ་ཙིནྟཱ་རཏྣ་ཀོ་ཥ་ནཱ་མ།

༄༅། །མ ཧཱ ཡཱ ནི ཨུ པ དེ ཤཤཱ སྱཱ ཙི ནཱ ར ཏྭཱཀོ ཥ ཐྲ ཏྟི པུཎྜ རཱི ཀ ནཱ མ བི ཧ ར ཏི སྨ།། །།

༄༅། །རྒྱ་གར་སྐད་དུ། མ་ཧཱ་ཡཱ་ན་ཨུ་པ་དེ་ཤ་ཤཱས་ཙིནྟཱ་རཏྣ་ཀོ་ཥ་དྲྀཏྟི་

༄༅། །པུཎྜ རཱིཀ མཱ ལ ནཱ མ མ ཧཱ ཡཱ ན ཨུ པ དེ ཤ ཤཱ སྱཱ ཙི ནཱ ར ཏྭཱ ཀོ ཥ སྱ ཊི ཀྐུ པུ སྟི ཀ པ B མཾ བི ཧ ར ཏི སྨ།། ། །

༄༅། །ཙིནྟཱ ར ཏྭཱཀོ ཥ ས ཌྷ ན ཡ ག ཙླི ར མ ཌྷ བ ཛུ ག གྷ ནཱ མ བི ཧ ར ཏི སྨ།། །།

།ཙི ན ར ཏྟཱ ཀོ ཥ སི དྷ ན ས མ སྟ བི ཧ རཾ།། །།

༄༅། །ཙི ནཱ ར ཏྟཱ ཀོ ཥ སྱ པ ཉྫི ཀཱ དཱི པ བྷ ཥཎ བི ཛ ཧ རཾ། །

།ཨ ཀྵ ད ཤ སྲ རྒ བཱ ཙ ཊི ཀྐཱ བི ཧ ར ཏི སྨ།།

།ཙི ན ར ཏྟཱ ཀོ ཥ སྱ ས མ ས ཀུ མུ དཾ མཱ ལ བི ཧ རཾ།། །།

༄༅། །ས སྟ མ ཧཱ ཀོ ཥ སྦྲ བི ཏ སཱ དྷཾ ཐུ ཨ ཀྵ ར ར ཏྭཱ ད རྣ བི ཧ རཾ།། །།

༄༅། །ཡཱ ན ས ཀ ལཱ རྦ དཱི པ སི རྞ ནྟི ར ཏྭཱ ནཾ ཀོ ཥ ནཱ མ བི ཛ ཧཱ ལཾ།། །།

༄༅། །རྒྱ་གར་སྐད་དུ། ཡཱ་ན་ས་ཀ་ལཱརྦ་དཱི་པ་སིདྡྷན་རཏྣ་ཀོ་ཥ་ནཱ་མ།

༄༅། ། །ཏ གྲྭ ཏཱ ར ཏྭཱ སྱ ཀོ ཥ ནཱ མ བི ཛ ཧཱ ལཾ།།

༄༅། །ཏྭཾ སེ ནཱ ག ཌྷ ནཱ མ རྦ བྲྀ ཏྟི སྟ ཐཱ ཏཱ ར ཏྭཱ སྱ ཀོ ཥ ནཱ མ ཊཱི ཀཱ བི ཛ ཧཱ ལཾ། །

༄༅། །རྒྱ་གར་སྐད་དུ། ཏ་ཐཱ་ཏཱ་རཏྣ་ཀོ་ཥ་ནཱ་མ་བྲྀཏྟི། བོད་སྐད་དུ།

༄༅། །ཡཱ ནཱ གྲ ར ཏྭཱ ཀོ ཥ སྱ པུ སྟི ཀ པ མཾ བི ཧ ར ཏི སྨ།། །།

།དྷ ཎྞཾ དྷུ ཏུ ར ༣ ཀོ ཥ ནཱ མ བི ཛ ཧཱ རོ།། །།
