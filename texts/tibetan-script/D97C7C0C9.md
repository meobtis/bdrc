# དགྱེས་པ་རྡོ་རྗེའི་སྒྲུབ་ཐབས་རིན་པོ་ཆེའི་སྒྲོན་མ།

བློ་གནས་པ་ལ་སྔགས་འདི་བརྗོད། །ཨོཾ་སྭ་བྷཱ་བ་ཤུརྙཿསརྦ་དྷརྨཱཿསྭ་བྷཱ་བ་ཤུརྙོཕོཧཾ།

མ་ཧཱ་རཱ་ག་དཏྟ་ཙ་ཏུ:ར་ཨཱ་1ནནྡ་བྷ་ག་2བི་ཤྭ་ཧཱུྃ་ཧཱུྃ་ཧཱུྃ་ཀརྱཾ་ཀུ་རུ་ཥྭ་མེ། པདྨ་
ཧཱ་:དྭེ་ཥ་3ཙ་ཏུ:ར་ཨཱ་ནནྡ་4དཱ་ཡ་ཀ་ཁ་ག་མུ་ཁ་ཨེ་ཀ་ར་སོ་ནཱ་ཐ་ཧཱུྃ་ཧཱུྃ་ཧཱུྃ་ཀརྱཾ་ཀུ་རུ་
ཥྭ་མེ། ཨོཾ་སརྦ་ཏ་ཐཱ་ག་ཏ་ཨ་ནུ་རཱ་ག་ཏ་བཛྲ་སྭ་བྷཱ་བ་ཨཱཏྨ་ཀོ྅་ཧཾ།དེ་ནི་སྦྱོར་

ཤེས་བདུད་རྩིར་འབབ། །:བྷྲཱུཾ་ཛྲཱྀཾ་ཨཱཾ་1ཁཾ་ཧཱུྃ་ལྔ་དང་། །ནཾ་2ཧཾ་ཤཾ་ཥཾ་གྷཾ་དང་ལྔ། །

ཐིམ༑ །ཨོཾ་སརྦ་ཏ་ཐཱ་ག་ཏ་པཱུ་ཛཱ་བཛྲ་སྭ་བྷཱ་བ་ཨཱ་་ཀོ྅ཧཾ། ལྷ་མོ་དེ་དག་་་

གནས་ལ། །ལྟེ་བར་ཧཱུཾ་ནག་འདབ་མ་ལ། །་ཧཱུཾ་ཛཱ་རྨཱ་②ཁཾ་ཨེ་ཝཾ་མ ཡོ་་་་

ཀྲྀཥྞ་4ཛཱི་མཱུ་ཏ་བ་པུ་ཥེ་ཀ་པཱ་ལ་མཱ་ལ་ཨ་2ནེ་ཀཾ་དྷ་རི་ཎེ། ཨཱདྷྨ་ཏ་ཀྲཱུ་ར་ཙིཏྟཱ་ཡ།
ཨརྡྷནྡུ་2དཾཥྚྲི་ཎེ། ཨོཾ་མཱ་ར་ཡ། མཱ་ར་ཡ། ཀཱ་ར་ཡ། ཀཱ་ར་ཡ། གརྫ་ཡ།
གརྫ་ཡ། ཏརྫ་ཡ། ཏརྫ་ཡ། ཤོ་ཥ་ཡ། ཤོ་ཥ་ཡ། སཔྟ་སཱ་ག་རཱན།

འདས་ཀྱི་རྩ་སྔགས་ཡིན། ཨོཾ་དེ་བ་པི་ཙུ་བཛྲ་ཧཱུྃ་ཧཱུྃ་ཧཱུྃ་ཕཊ་སྭཱ་ཧཱ། སྙིང་པོའི་
སྔགས་སུ་ཤེས་པར་བྱའོ། །ཨོཾ་བཛྲ་ཀརྟ་རི་ཧེ་བཛྲཱ་ཡ་ཧཱུྃ་ཧཱུྃ་ཧཱུྃ་ཕཊ་སྭཱ་ཧཱ། དེ་
ནི་ཉེ་བའི་སྔགས་ཀྱང་ཡིན། ཨོཾ་ཨ་ཀ་ཙ་ཊ་ཏ་ཕ་1ཡ་ཤ་ཧཱུྃ་སྭཱ་ཧཱ། གྲོང་ཁྱེར་
དཀྲུག་པའི་སྔགས་ཡིན་ནོ། །ཨོཾ་ཏྲི་ལོཀྱཱ་ཀྵེ་པ་:ཧཱུྃ་ཧཱུྃ་ཧཱུྃ་2ཕཊ་སྭཱ་ཧཱ། ཕྱག་
