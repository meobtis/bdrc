# ཀློང་སྙིང་སྒྲུབ་མཆོད་ལས་འགྲིག་དང་དཔེ་རིས།

འབུད་རྐྱང་མ） སུམ་བརྡུང་། ཧཱུྃ་དབྱིངས་ནས་ = སོགས། ཨཱ༔ ཧཱུྃ
༡ ཨོཾ་ཨཱ༔ ཧཱུྃ ༔ སརྦ་པཉྩ་ = སོགས།༣ ཨོཾ་ཨཱ༔ ཧཱུྃ་མ་ཧཱ་ - སོགས། ༣ ཨོ་ཨཱ༔ ཧཱུྃ་མ་ཧཱ་

བཛྲ་ས་མཱ་ཛ༔ ཐང་ཐང་གཅིག་ནས་སུམ་རྐྱང་། ཧཱུྃ་བདེ་གཤེགས་ = སོགས། ཆེན་པོར་བསྔོ༔ རཾ་ཡཾ་ཁཾ། ཨོཾ་ཨཱ༔ ཧཱུྃ། ཧཱུཾ་ང་ནི་ = སོགས་ནས། ཧཱུཾ་ཧཱི

ཧཱུྃ། གཅིག ཨོཾ་ཨཱ༔ ཧཱུྃ་སརྦ་པཉྩ་ = སོགས། ལན་གསུམ་འདོན་ནས་ཌ་འུར། ཨོཾ་ཨཱ༔ ཧཱུྃ་མ་ཧཱ་བྷ་ལིང་ = སོགས། ལན་གསུམ་མཐར། ཌ་འུར། ཨོཾ་ཨཱ༔ ཧཱུྃ་མ་ཧཱ་

སྙིང་རྗེས་བསྒྲལ་ = སོགས། བསྒོམ། དགུ་འཐེང་། （ རྐང་ཐང་དལ་འདོན།) ཨོཾ་བཛྲ་ཀཱི་ལི་ཀཱི་ལ་ཡ་སརྦ་བིགྷན་ཁཾ་ཧཱུཾ་ཕཊ། ཨོཾ་རུ་ལུ་རུ་ལུ་ཧཱུྃ་སྦྱོ་ཧཱུཾ། ལན་

ནམ་མཁའ་མེད་པར་ སོགས། ༈ ཚེ་ཁྲུས་སྐབས་ཀྱི་སྔགས་ནི། ཨོཾ་བཛྲ་ཀཱི་ལི་ཀཱི་ལ་ཡ་སརྦ་བིགྷཱན་པཾ་ཧཱུྃ ཕཊ། ཨོཾ་རུ་ལུ་རུ་ལུ་ཧཱུཾ་སྦྱོ་ཧཱུྃ། ༈ འདི་དལ་མོས་བཏོན་ལ) ཧཱུྃ་སྙིང་

ཧུ་ཤྲཱི་ཝ་ཧཱུྃ་ཕཊ རང་ཉིད་སྐད་ཅིག་གིས་ = སོགས་ནས། སྐུར་གྱུར། ཨོཾ་ཧུ་ཤྲཱི་ཝ་ཧཱུྃ་ཕཊ༔ ཨོཾ་སྭ་བྷཱ་བ་ཤུདྷུ ༔ སོགས་སྟོང་པ་ཉིད་དུ་གྱུར།

གསལ = སོགས། ཚུར་བྱོན།།སྔགས་རོལ། བརྡུང་། ཧཱུྃ་བཞེངས་ཤིག – སོགས། ཏིཥྛ་ལྷན༔ རཾ་ཡཾ་ཁཾ། ཨོཾ་ཨཱ༔ ཧཱུྃ། ཧ་ཧོ་ཧི༔ ན་མ༔ སརྦ = སོགས།

མ། རྔ་བཅས། རཾ་ཡཾ་ཁཾ – སོགས། ཁཱ་ཧི། ཨོཾ་རུ་རུ་ཧེ = སོགས། ཧཱུྃ༔ ས་པཱ་རི – སོགས བ་ལིརྟ་ཁ་ཧཱི། ལན། ༣ ཧཱུྃ་སྐུ་གསུམ་ཞིང = སོགས། མཛོད།

ཏ = སོགས། གྱིས་བགེགས་སྐྲད། ཛ ཧཱུྃ པཾ་ཧོ། ཨོཾ་བཛྲ་ཨཀྵེ་ཡེ་ = སོགས ཡཾ་རཾ རྩ་གདངས། ཧཱུཾ་མེ་ལྷ་དྲང་སྲོང་ = སོགས། ཨཱ༔ ཧཱུྃ། བྱོན་སྐྱེམས་ནི། ཨོ་

གསུམ། ཧཱུཾ་ཧཱུཾ་ཧཱུཾ། རྗེ་བཙུན་སོགས། ཧཱུྃ་བཞེངས་ཤིག་པདྨ་= སོགས། དེ་ནས་གཞུང་གིཧཱུྃ་ཕཊ་མཆོག་ = སོགས་བྱིན་འབེབས་མཐོར། ཧཱུྃ། བྱིན་རླབས་ཀུན་ སོགས། དངོས་

ཧཱུཾ་བཾ་

ཡ་ཕཊ༔ ༈ ཏྲི་ཤ་ཧཱུཾ་མ་ར་ཡ་ཆད་སོད། ཨོཾ་ཤྲཱི་མ་ཧཱ་ཀཱ་ལ་ས་པ་རི་ཝཱ་ར་ = སོགས། སཱ་ཧཱ། སྡང་བའི་དགྲོ་དང་ = སོགས། བར་ཆ་ལ་པ་གགཏོར་

མེད་པར་བསམ། ཧཱུྃ་ མགོན་པོ་ཆེན་པོའི་ = སོགས། ཕྲིན་ལས་མཛོད། ཨོཾ་ཤྲཱི་མ་ཧཱ་ཀཱ་ལ – སོགས ཧཱུྃ་ཕཊ ཧཱུཾ་ལྷ་དམག་བྱེ་བའི – སོགས། ལས་
པའི་ – སོགས། མེད་པར་བསམ་ལ། ཧཱུྃ གཞན་ཡང་བཀའ་ཉན་ – སོགས། ཕྲིན་ལས་མཛོད༔ ཨོཾ་ཤྲཱི་མ་ཧཱ་ཀཱ་ལ་ = སོགས། ཧཱུྃ་ཕཊ ༔ ཧཱུྃ་ ཡང་

ཤ་ཡ་ཨཱ༔ ལན་བདུན་ནམ་གསུམ། ཨོཾ་ཤྲཱི་མ་ཧཱ་ཀཱ་ལ – སོགས་ པཾ་ཧོ༔ ལན། ༣ ཧཱུྃ་ སྔོན་གྱི་བསྐལ་པ་ = སོགས། མ་ལྡང་ཅིག ཨོཾ་ཤྲཱི་མ་ཧཱ་ཀཱ་ལ་ = སོགས།

ཐིམ་པར་བསམ། ཧཱུཾ་ང་ནི་དཔལ་ཆེན་ = སོགས། ཀི་ལ་ཡ། ཁ་ཁ་ཁཱ་ཧི་ཀཱི་ལ་ཡ་ = སོགས། ཧཱུྃ་ཕཊ། བསྟབ་པ་ནི། ཧཱུྃ་མ་ཧཱ་ཀཱ་ལའི་ཞལ་དུ་ - སོགས་

དྲུག་བཟླ༔ ཨོཾ་མ་ཎི་ཧཱུྃ་ཧི༔

ཨོཾ་ན་མ ས་མནྟཱ་མཎྜལ་ཧཱུྃ་རེ་དང་། སྒྲུབ་སྔགས་ཧཱུྃ་བཛྲ་ཙི ཏྟ་ = སོགས་ནས་དྷ་ར་ན་སྦྱོའི་བར་གྱིས་བཀོད། གཞུང་ལས། ཨོཾ་ཨཱ༔ ཧཱུྃ་ས་མ་ཡ་ཧཱུྃ སློབ་

ཁཾ༔ ཨོཾ་སྭཱ་བྷ་ཝཾ – སོགས། སྟོང་པའི་ངང་ལས – སོགས། ཧཱུྃ་ཛ༔ རོལ། (རྒྱ, ཛ ཧཱུྃ་བོ ཧོ༔ ཨོ་དྷི་ཏ་རསྨཱ – སོགས། (རྒྱ པྲ་ཏི་ཙྪ་སྭཱ་ཧཱ། རོལ། ཨོཾ་ཨ་ཀཱ་

བཞུགས་ནི། ༀ་ཛི་ན་ཛིཀ ལོ་དེ་ཁ་ར་ཏི། ཨོཾ་ཨཱ་རོ་ལིཀ པཱ་ར་ག་ར་ཏི། ཧཱུྃ་བཛྲ་དི ཀ ཨཾ་དྷཱ་ཏི་ཤྭ་རི། ཨོཾ་ཨཱ་ཧཱུྃ་སྭཱ་ཧཱ། ལན་གསུམ།

བ ། ཁྲོའི་ཚོང་པ་འིབུ ལཊྛིཏཾ ཨོཾ་ཨཱབཛ་ཅུ་པ་པྲ་ཏི་ཛ་ཧཱུྃ ༔ ཧཱུྃ་ སྣོད་བཅུད་སྣང་སྲིད་སོགས་ བརླབ་ཏུ་གསོལ༔

N། ལཱལ་ཞུསང ཨོཾ་ཨཱ ཧཱུྃ་སཉྩ་ཨ་མྲྀ་ཏ་ཧཱུྃ་ཧ་ཧོ་ཚི༔ ལྷག་མའི་དམ་རྫས་འདོད་ཡོན་གྱི་ཕུང་པོ་ཟད་མི་

ནཾ གྱི་ཀུན་སཎོ ཨཾ བློ་ཡི་དི་ ཚྭབ་ག་ས༌ ཧཱུཾ། ཀླུ་ཡི་དི་སྤྲོ་སཊ༌ ཡི་གེ་ཀྱ་ས་བགྱས་ནས། ཨོཾ་ཨཱ༔ ཧཱུྃ་བྷོ་དྷི་ ཟད་ཙེད་མ་
