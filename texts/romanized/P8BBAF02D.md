# Mātṛceṭa: Śatapañcāśatka

## Chapter 10: Mārgaāvatārastavaḥ

|| khyod ni rṅan then bgyid la skul | | chom rkun bgyid pa tshar yaṅ gcod || gya gyu can rnams
rnal du ’god | | dal bus bgyid la gźen skul ’debs |

| dul (4)ba rnams ni lam la sbyor | | dmu rgod rnams la btaṅ sñoms mdzad || de slad skyes bu
’dul ba yi | | kha lo sgyur ba bla med mchog |

| khyod ni ñam thag rnams la brtse | | bde bar gnas la phan par dgyes || phoṅs par gnas la thugs
rje bas | | kun la phan par (5)bźed pa lags |

| khyod ni dgra bo rnams la’aṅ byams | | ñams par gyur la phan ’dogs mdzad || gtum po rnams
la thugs brtse bas | | khyod ni ya rabs rmad cig lags |

| phan ’dogs bgyid slad pha ma dag | | gal te bla mar ’tshal na go || khyod ni lhag par phan
(6)’dogs pas | | bla ma ñid gyur smos ci ’tshal |

| raṅ gi don la mi lta bas | | ñid kyi dgra bo ltar gyur ciṅ || g-yaṅ sa’i mun na gnas rnams
la | | ra ba lta bur gyur pa’aṅ khyod |

| ’jig rten gñis kar sman gdags daṅ | | ’jig rten las ni ’da’ slad du || mun par (7)gyur pa’i
’jig rten la | | khyod kyis śes rab snaṅ bar mdzad |

| yul la ñe bar spyod pa na | | lha mi’i spyod pa tha dad kyaṅ || chos kyi loṅs spyod thun moṅ
bas | | khyod la dbye ba mi mṅa’o |

| bcom ldan khyod kyis skye ba daṅ | | na tshod rigs daṅ yul daṅ ni || dus kyi skyon (114b1)med
chos rnams kyis | | ’di dag kun la sman yon btags |

| khyod kyi ñan thos srid bral źiṅ | | ya mtshan ’dzin pa med rnams la’aṅ || lha rnams thal
sbyar smon bgyid ciṅ | | ya mtshan che ba lta bur mchod |

| e ma’o saṅs rgyas ’khor ba yi | | ñid gur gyur pa byuṅ (2)ba brjid || des ni mi yaṅ lha rnams
kyis | | smon par bya ba ñid du gyur |

| lam la ’jug pa la bstod pa ste le’u bcu pa’o ||

## Chapter 11: Duṣkarastavaḥ

|| mñel daṅ źe bde ñams gyur daṅ | | skye bo ṅan daṅ ’grogs pa daṅ || mi mthun pa daṅ maṅ po
yi | | skyon yaṅ yon tan bźin dgoṅs (3)śiṅ |

| ’gro ba’i don slad ma chags pa’i | | thugs kyis brtson pa gaṅ mdzad pa || saṅs rgyas rnams
kyi saṅs rgyas kyi | | chos ñid bcom ldan de rmad do |

| bśos kyaṅ phal pa gsol mdzad ciṅ | | res ’ga’ smyuṅ ba dag kyaṅ mdzad || ñam ṅa’i śul du’aṅ
gśegs (4)mdzad ciṅ | | rad rod can du’aṅ mnan la mdzad |

| mgon khyod gtso bor gyur lags kyaṅ | | gdul bya rnams la byams slad du || sku ṅas brṅo daṅ
gcam tshul daṅ | | skad daṅ cha lugs sgyur ba’aṅ mdzad |

| kun gyis dga’ mgur raṅ don phyir | | bran bźin bskor bar bsgrims (5)pa las || mgon khyod rtag
tu bdag ñid la | | mṅa’ ma mchis pa’aṅ ma lags so |

| khyod la gaṅ daṅ gaṅ du yaṅ | | ji skad bskul ba’aṅ mi spoṅ ste || ñid kyi sgrub pa bzaṅ po
las | | ’da’ bar ’gyur ba ma mchis so |

| ji ltar khyod ni gnod bgyid la | | phan pa lhur mdzad (6)de lta bur || skye bo dag ni phan
bgyid la’aṅ | | phan pa de ltar lhur mi bgyid |

| khyod ni gnod bgyid dgra bo la | | phan pa mdzad pa’i bśes lags te || rtag tu skyon dag tshol
ba la | | yon tan ’ba’ źig tshol ba lags |

| khyod ni gaṅ na dug bcas śiṅ | | źugs daṅ bcas par (7)spyan draṅs pa || der ni brtser bcas
gśegs pa daṅ | | khyod la bdud rtsi can du gyur |

| bzod pas mi sñan brjod pa daṅ | | ’khu ba dag ni bde legs kyis || mi sñan smra la bden pas
te | | khyod kyis sdaṅ ba byams pas btul |

| thog ma med dus goms pa yis | | mi yi raṅ (115a1)bźin maṅ po yaṅ || khyod kyis ṅan soṅ rnam
bzlog nas | | skad cig ñid la yoṅs su bsgyur |

| dka’ ba mdzad pa bstod pa ste le’u bcu gcig pa’o ||

## Chapter 12: Kauśalastavaḥ

|| rtsub pa daṅ ’jam bgyis pa daṅ | | ’juṅs pa rnams ni gtoṅ phod daṅ || gtum pa des (2)par
bgyis pa gaṅ | | de ni khyod kyi thabs mkhas lags |

| dga’ bo’i dbaṅ po ñer źi daṅ | | ṅa rgyal kheṅs pa ’dud pa daṅ || sor mo’i phreṅ ba’aṅ źi
bgyis na | | su źig ṅo mtshar bskyed mi bgyid |

| khyod kyi chos kyi ros tshim pas | | gser las bgyis pa’i lam spaṅs (3)nas || ran maṅ btiṅ
ba’i gnas mal du | | brten rnams bsod ñams ñal bar bgyid |

| khyod kyis dus daṅ bsam mkhyen pas | | res ’ga’ źus na’aṅ mi gsuṅ la || spros gyur gźan la
bstan pa daṅ | | druṅ du gśegs nas bśad pa’aṅ mdzad |

| dri med gos la tshon (4)bźin du | | thog mar sbyin sogs gtam dag gis || sems la spro ba bskyed
nas ni | | phyi nas chos ni bstan pa mdzad |

| ’khor ba mi bzad gtiṅ nas ni | | ’gro ba ñon moṅs draṅ slad du || khyod kyis gaṅ źig ma stsal
ba’i | | thabs daṅ spyod pa de ma mchis |

| sku yi cha lugs (5)rnam maṅ daṅ | | gsuṅ gis so so’i skad bźin du || gdul bya’i bsam pa tha
dad pa | | de daṅ der ni khyod kyis mdzad |

| de dag kun kyaṅ dag pa daṅ | | mi ’gal ba daṅ mchod ’os daṅ || brjid daṅ lha mi rnams la ni
| | sman ’dogs bkur ba śa stag lags |

| smra daṅ (6)bgyid pa phal cher ni | | legs par rdo thogs ma lags kyi || bden par gsuṅ ba khyod
la ni | | de gñis gźan du gda’ ba lags |

| bdag ñid dag pa ’ba’ źig gis | | khyod kyis ’gro ba’i dpal źiṅ mdzad || ’di ltar rnam pa ’di
’dra’i źiṅ | | ’jig rten gsum na (7)mchis ma lags |

| thog med srid pa ñam ṅa bar | | sṅa nas gcig tu ñams pa yi || sems can kun la sman slad du
| | khyod ni de ltar brtson pa lags |

| mkhas pa la bstod pa le’u bcu gñis pa’o ||

## Chapter 13: Ānṛṇyastavaḥ

|| gaṅ gis khyod drin lan lon pa’i | | sgrub de mchis (115b1)sñam mi bgyid de || skye bo gaṅ
dag mya ṅan ’das | | de dag gis kyaṅ lan ma lon |

| khyod kyi chos la gnas de dag | | raṅ don kho na bgyid par bas || de yi slad du ’o brgyal
gaṅ | | de la lan go ci źig lon |

| khyod ni sems can gñid log pa’i | | rgyud la gzigs pa’i (2)źugs tse ba || bag med gyur pa
rnams kyi ni | | grogs bzaṅ bag daṅ bcas pa lags |

| khyod kyis ñon moṅs gźom pa bśad | | bdud kyi g-yo dag bstan pa mdzad || ’khor ba’i raṅ bźin
mi bzad brjod | | ’jigs pa med pa’i phyogs kyaṅ bstan |

| phan dgoṅs (3)thugs rje can gyis ni | | sems can rnams la bgyi ’tshal ba || gaṅ źig khyod
kyis ma mdzad pa | | gźan go ci źig mchis lags kye |

| gal te chos ni ’di dag daṅ | | spo ba źig tu btub na ni || gdon mi ’tshal bar khyod kyis ni
| | lha sbyin la brten kun la’aṅ stsol |

| de (4)slad ’gro la brda sprod pa | | ’gro ba’i mgon po khyod kyis ni || ’di na phan tshun
byed pa po | | med pa skad du ṅes par gsuṅs |

| ’jig rten rnams la thugs brtse bas | | yun riṅs sa steṅs dam chos bśad || ’jig rten gsum phan
’dogs nus pa’i | | slob ma dam pa’aṅ (5)maṅ du bskrun |

| mṅon du gdul bya’i tshogs kyaṅ ni | | mdzes bzaṅs yan chad btul lags pas || da go khyod la
sems can gyi | | bu lon lhag ma ci mchis na |

| ’di ltar rdo rje’i tiṅ ’dzin gyis | | sku gduṅ til ’bru bźin blags nas || mjug tu’aṅ khyod
kyis śin tu ni | | (6)dka’ spyad yal bar ma dor ro |

| gzugs kyi sku daṅ chos ’di dag | | gźan don kho nar mdzad do źes || ’jig rten yid ches dka’
’di la | | khyod kyis mya ṅan ’das pa bstan |

| de slad chos sku ma lus pa | | sras kyi mchog la gtad mdzad de || gzugs sku til ’bru ltar
(7)bśig nas | | khyod ni yoṅs su mya ṅan ’das |

| e ma’o gnas pa e ma’o tshul | | e ma’o yon tan e ma’o sku || saṅs rgyas kyi ni chos rnams
la | | ya mtshan mi che ’ga’ ma mchis |

| phan ’dogs mdzad ciṅ blta na sdug | | sku gsuṅ phrin las źi gyur pa || khyod la’aṅ (116a1)sdaṅ
bar rab bgyid pa’i | | rmoṅs pa mi bzad pa la gzigs |

| bsod nams rgya mtsho rin chen gter | | yon tan ’byuṅ gnas chos kyi tshogs || khyod la sems
can gaṅ ’dud pa | | de dag la yaṅ phyag ’tshal legs |

| mgon khyod yon tan mi bas kyaṅ | | (2)bdag gi źo śa bas ’tshal bas || des na ’jigs pa mchis
slad du | | glo ba la ni bcags bźin mchis |

| khyod kyi raṅ gi ṅo bo ñid | | tshad ma mchis la bsam mi khyab || bstan min graṅs kyaṅ ma
mchis pa | | khyod bdag ñid kyis mkhyen lags graṅ |

| mtsho chen chab ni (3)bas par ma gyur kyaṅ | | skye bo’i gduṅ ba rab tu źi bgyid ltar || khyod
kyi yon tan cha tsam ma bsgrags kyaṅ | | bdag ni mchog tu glo pa dga’ źiṅ mchis |

| bdag gis thub la dad pas spobs skyes pa’i | | dge ba’i las ’di’i ’bras bu ’khruṅs pa yis ||
ṅan rtog rluṅ dmar (4)’tshubs pas dkrugs pa yi | | ’gro ba’i sems ni rnal du gnas par śog
|

| bu lon med par bstod pa ste le’u bcu gsum pa’o ||

## Chapter 1: Upodghātaḥ

| gaṅ źig la ni ñes pa kun | | gtan nas yoṅ ye mi mṅa’ źiṅ || gaṅ la’aṅ rnam pa thams cad du
| | (4)yon tan thams cad gnas gyur pa |

| gal te sems śig yod na ni | | de ñid la ni skyabs ’gro źiṅ || de bstod de ni bkur ba daṅ |
| de yi bstan la gnas pa’i rigs |

| thams cad mkhyen pa yon tan kun | | mṅa’ la de yaṅ ñam mi mṅa’ || ñes pa bag chags (5)bcas
de yaṅ | | skyob pa gcig pu la mi mṅa’ |

| bcom ldan ’das kyi sku daṅ ni | | gsuṅ daṅ thugs kyi phrin las la || źe ’gras gyur pa gaṅ
gis kyaṅ | | chos daṅ ldan par glags mi rñed |

| rgya mtshor gña’ śiṅ bu ga ru | | rus sbal mgrin pa chud pa ltar || dam (6)chos dga’ ston
cher bcas pa’i | | mi ñid bdag gis thob nas ni |

| mi rtag ñid daṅ rjes ’brel źiṅ | | las kyi klags la dogs bcas pa || bdag gi lce ’di ñid kyis
go | | sñiṅ po ci phyir blaṅ mi bya |

| de ltar thub pa’i yon tan kyi | | yul lta graṅs med śes mod kyi || (7)raṅ gi don la gus pa
yis | | de yi phyogs gcig bsgribs te brjod |

| gaṅ gi yon tan graṅs dag daṅ | | mthu la thug pa ma mchis la || rmad byuṅ phrin las dpag med
can | | raṅ byuṅ khyod la phyag ’tshal lo |

| ’di sñed bgyi ba’i mtha’ med na | | ’di ltar lags źes (110b1)ci źig smos || khyod kyi yon
tan slad du bdag | | bsod nams sñam nas spyi brtol skyes |

| bstod pa gleṅ bslaṅ ba ste le’u daṅ po’o ||

## Chapter 2: Hetustavaḥ

|| spyod dam mi spyod sñam pa yi | | rnam par rtog pa rnams spaṅs nas || ’gro ba ’di ni ñam
thag ces | | khyod bdag ñid kyis źal (2)gyis bźes |

| khyod ni ma bcol lags mdzad pa | | khyod ni rgyu med bźin du byams || khyod ni ma ’dris mdza’
bśes te | | ’brel pa med pa’i gñen ’dun lags |

| ñid kyi śa yaṅ stsol mdzad na | | dṅos po gźan lta smos ci ’tshal || legs mdzad khyod kyis
srog kyaṅ ni | | (3)sloṅ ba’i skye bo rnams la btaṅ |

| ñid kyi sku daṅ srog dag gis | | lus can gśed mas zin rnams kyi || lus daṅ srog kyaṅ khyod
kyis ni | | lan brgya phrag du bslu ba mdzad |

| ṅan ’gros bsñeṅs slad ma lags la | | bźed pa’i ’gro ba’aṅ sgrub ma lags || dgoṅs pa (4)dag
pa ’ba’ źig gis | | khyod kyis tshul khrims goms par mdzad |

| rtag tu gya gyu rnam spaṅs śiṅ | | draṅ brtan rnams ni rtag bsten pas || yoṅs su dag pa’i
las rnams kyis | | khyod ni gźi rten gcig pur gyur |

| sdug bsṅal maṅ pos gzir ba na | | khyed (5)kyis dge ba’i thugs kyis ni || ñon moṅs rnams la
sran btsugs nas | | skye bo ñon moṅs can la brtse |

| khyod kyis gźan gyi don slad du | | sku srog btaṅ nas dgyes gyur gaṅ || de ’dra srog chags
’gums pa las | | sos pa rnam la’aṅ byuṅ ma gyur |

| khyod ni lan (6)’ga’ ma lags par | | gtubs kyaṅ sdug bsṅal mi dgoṅs par || gśed pa ma bgyid
pa’i sems can la’aṅ | | gtso bo thugs rjer gyur pa gaṅ |

| khyod kyi thugs ni rin po che | | rdzogs pa’i byaṅ chub sa bon te || dpa’ khyod kho nas sñiṅ
por mkhyen | | de gźan skye bos (7)’ol mi mchi |

| dka’ spyad las ni ma bgyis par | | go ’phaṅ rñed dka’ mi ’thob ces || de slad ñid la’aṅ ma
gzigs par | | khyod kyi brtson ’grus legs par spel |

| khyad par ’phags par bgyi ba la | | khyod la thaṅ lhod ’ga’ ma byuṅ || de slad khyod kyi khyad
par rnams | | (111a1)thog druṅ rim pa dbyer ma mchis |

| thugs ni thugs rje chen po daṅ | | rtag tu rjes su ’brel slad du || tiṅ ’dzin ’bras bur bcas
pa yi | | śin tu bde la’aṅ khyod ma chags |

| gźan daṅ thun moṅ ma lags pa’i | | bde ba gaṅ de gya nom yaṅ || dam (2)pa’i spyod ldan khyod
’dra la | | gnod par bas kyi sman ma mchis |

| ’dres pa las ni legs bśad ñid | | sñiṅ po skyon med ñi tshe źig || khyod kyis kun bźes thugs
la bźag | | ñes bśad dug bźin yoṅs su spaṅs |

| rin chen sñiṅ po mkhyen khyod kyis | | legs (3)bśad srog gis ’jal ba na || skye ba de daṅ
de dag tu | | byaṅ chub slad du dpa’ rtsal bstan |

| de slad graṅs med gsum dag tu | | khyod ni de ltar brtson pa na || brtson ’grus ’ba’ źig grogs
gyur pas | | go ’phaṅ bla na med pa brñes |

| rgyu la bstod pa ste le’u gñis (4)pa’o ||

## Chapter 3: Nirupamastavaḥ

|| mtho la phrag dog mi mdzad ciṅ | | dma’ la rṅan can mi mdzad la || mñam la ’gran pa mi mṅa’
bas | | khyod ni ’jig rten gtso bor gyur |

| khyod ni yon tan rgyu rnams la | | mṅon bgyis ’bras bu rnams la min || yaṅ dag sgrub pa de
ñid kyis | | (5)khyod kyi yon tan pha mthar phyin |

| ji ltar khyod kyi źabs rdul yaṅ | | bsod nams skye ba mched ’gyur ba || de ltar khyod kyis
legs spyad pas | | bdag ñid rab tu bskrun pa mdzad |

| ñes pa ñams smad rtsa nas bton | | yon tan spel nas rnam par sbyaṅs || gźuṅ (6)lugs bzaṅ po
des na khyod | | grub mchog lhag par brñes pa lags |

| ji ltar bdag gi rgyud la de | | bag chags lhag ma’aṅ ma lus pa || de ltar rnam par thams cad
du | | ñes pa khyod kyis rab tu bcom |

| ji ltar gźan la de dag daṅ | | ’dra ba tsam yaṅ mi (7)gda’ ba || de ltar khyod kyis bsags
bsags nas | | bdag ñid la ni yon tan bsgrubs |

| ’jig rten pa yi dpe dṅos kun | | gegs bgyid pa daṅ sgrib pa can || re źig pa daṅ ñi tshe ba
| | śin tu rñed par sra ba lags |

| khyod kyis yon tan bla med la | | gegs bgyid (111b1)ma mchis rtogs ma mchis || brtan pa daṅ
ni rgyun chags pas | | dpe lta mchis par ga la ’gyur |

| gaṅ tshe khyod kyi dgoṅs pa’i dkyil | | gtiṅ daṅ pha rol med brtags na || rgya mtsho zab pa
ñid kyaṅ ni | | gnag rjes lta bur sa ler gda’ |

| chos rnams kun gyis mi bskyod (2)pa | | khyod kyi brtan pa mṅon bsams na || sa yi brtan pa
ñid kyaṅ ni | | śir śa’i ge sar rtse ltar chuṅ |

| thub pa khyod kyi ye śes kyi | | snaṅ bas mi śes rab rib dag || ’joms pa’i thad na ñi ma yaṅ
| | me khyer tsam du’aṅ mi spyod do |

| khyod kyi gsuṅ thugs mdzad spyod rnams | | (3)dag pa’i gan na ston zla daṅ || chu daṅ nam
mkha’i dag pa rnams | | dri ma can ni lta bur gda’ |

| ’jig rten legs pa gaṅ ci’aṅ ruṅ | | thams cad bsṅos na’aṅ der bas te || ñon moṅs ’jig rten
chos rnams kyis | | saṅs rgyas chos la khyad mi khor |

| rin chen chos gaṅ brñes (4)nas khyod | | mchog tu gyur pa de ñid daṅ || khyad du bsgrun źiṅ
de daṅ ni | | khyod daṅ bsgrun ldom kho nar bas |

| gaṅ la spyi tsam bstun nas ni | | cuṅ zad brjod par bgyid pa de || smra ba po yi raṅ dga’
daṅ | | thabs daṅ gcam bu tsam du bas |

| dpe med pa la bstod pa ste le’u gsum (5)pa’o ||

## Chapter 4: Adbhutastavaḥ

|| khyod ni bdud las rnam rgyal te | | ’gro kun dad par mdzad pa yaṅ || bdag gis chos ñid rjes
bsams na | | chen po ltar gaṅ ma mthoṅ ṅo |

| sdaṅ bas rgol bar rtsol byed pa | | maṅ po’aṅ gźom par bya ba ni || khyad par gnas la brten
pa yi | | bzod pa’i tshigs (6)su mtshar mi che |

| gaṅ tshe bdud rnams mṅon btul ba | | de yi nub mo kho na la || ñon moṅs śin tu che spaṅs pa
| | de ñid rmad du byuṅ ba lags |

| ’od zer phreṅ ba stoṅ ldan pa’i | | ñi mas mun bsal gaṅ lags daṅ || dpa’ bo khyod kyis mu
stegs las | | rgyal bar mdzad pa (7)ci źig mtshar |

| ’dod chags bral bas chags bcas daṅ | | źe sdaṅ bral bas źe sdaṅ can || gti mug bral bas rmoṅs
pa ste | | gsum pos rtag tu gsum dag btul |

| dam chos rab tu bstod pa daṅ | | dam chos ma lags smod mdzad kyaṅ || dam pa dag daṅ tha ma
la | | (112a1)khyod ni chags daṅ khro mi mṅa’ |

| dgra bcom pa daṅ mu stegs la | | rjes su chags daṅ khoṅ khro bar || khyod kyi thugs ni mi
’gyur na | | khyod la bstod du ci źig mchis |

| yon tan rnams la’aṅ ma chags la | | yon tan can la’aṅ bźed mi mṅa’ || kye ma’o (2)khyod kyi
thugs stobs ni | | rab daṅ yoṅs su dag pa lags |

| dbaṅ po rnams ni rab daṅ ba | | dus rnams rtag tu mi ñams pas || khyod thugs rtag tu daṅ ba
dag | | mṅon sum gyur pa bźin du gda’ |

| raṅ bźin dam pa legs gsuṅs daṅ | | mdzad spyod bzaṅ pos (3)bsgrags pas na || khyod kyi blo
gros dgoṅs pa dag | | rnam dag byis pa’i bar la grags |

| rmad du byuṅ ba’i bstod pa ste le’u bźi pa’o ||

## Chapter 5: Rūpastavaḥ

|| ñe bar źi la yid du ’oṅ | | ’bar la gnod pa mdzad mi mṅa’ || dul la rṅom brjid che ba yis
| | sku ’dis su źig dad mi (4)mdzad |

| khyod kyi sku de gaṅ gis na | | lan brgyar mthoṅ daṅ gaṅ źig gis || daṅ por mthoṅ ba de gñis
ka | | ’dra bar mig ni mgu bar mdzad |

| khyod kyi sku ni mdzes pa’i phyir | | blta bas mi ṅoms raṅ bźin pas || mthoṅ ṅo cog ni phyi
phyir źiṅ | | dga’ ba bskyed (5)par mdzad pa lags |

| rten gyi yon tan dag daṅ ni | | brten pa’i yon tan phan tshun du || ’tsham pas khyod kyi sku
daṅ ni | | yon tan phun tshogs mchog daṅ ldan |

| mtshan daṅ dpe byad bzaṅ ’bar ba | | khyod kyi sku las ma gtogs pa || de bźin gśegs pa’i yon
tan (6)’di | | gźan gaṅ źig la legs gnas ’gyur |

| khyod sku rten pa’i yon tan la | | ṅa dpal che źes gsuṅ gsuṅ ltar || de yi yon tan rnams kyaṅ
slar | | des legs bkod ces gsuṅs pa ’dra |

| sku la bstod pa ste le’u lṅa pa’o ||

## Chapter 6: Karuṇāstavaḥ

|| ’gro ba ’di dag (7)thams cad ni | | khyad med ñon moṅs rnams kyis bciṅs || khyod ni ’gro
ba’i ñon moṅs dag | | dgrol slad yun riṅ thugs rjes bsdams |

| daṅ por khyod la phyag bgyi’am | | ’on te gaṅ gis ’khor bar khyod || skyon mkhyen yun riṅ
de lta bur | | bźugs mdzad thugs rje (112b1)che la bgyi |

| dben pa’i bde ba spaṅ gyur khyod | | maṅ po’i naṅ du bźugs pa gaṅ || de khyod thugs rjes dus
’das pa | | glags śig thod nas bgyis par bas |

| rig pa yis ni mtsho naṅ nas | | klu bźin khyod kyi thugs rje yis || dgon pa źi gnas groṅ gi
mthar | | gdul ba’i don (2)gyi slad du draṅs |

| ñer źi mchog la gnas bźin du | | thugs rje gtso daṅ ldan pas na || rol mo mkhan gyi sgyu rtsal
yaṅ | | khyod kyi źabs kyi ’dor bar mdzad |

| rdzu ’phrul seṅ ge’i sgra daṅ ni | | ñid kyis yon tan brjod pa gaṅ || de ni bźed spyod mi
mṅa’ ba | | khyod kyi thugs rjes (3)bstan pa lags |

| gźan gyi don du rab bzaṅ gi | | ñid kyi don la brtse med pas || mgon po khyod ñid ’ba’ źig
la | | thugs rjes thugs rje mdzad ma gyur |

| ’di ltar res ’ga’ brtan pas gaṅ | | gźan don bsgrubs mdzad slad du || khyod ni lan brgyar
phyogs dag tu | | (4)gtor ma bźin du btaṅ ba lags |

| de ltar khyod la gnod mdzad kyaṅ | | noṅs pa can du mi rtsi bas || khyod kyi bźed pa kho na
daṅ | | mthun ’jug pa ni lags par gda’ |

| thugs la bstod pa ste le’u drug pa’o ||

## Chapter 7: Vacanastavaḥ

|| tshig bzaṅ ba daṅ don che daṅ | | bden pa daṅ ni sñam pa daṅ || (5)zab gsal gñis ka’i don
ldan daṅ | | bsdus daṅ spros pa daṅ ldan pa |

| khyod kyi gsuṅ ni de lta bu | | khyod kyi dgra bos thos na yaṅ || thams cad mkhyen pa lags
so źes | | su źig jes pa skye mi ’gyur |

| maṅ po ril gyis sñan pa lags | | bcos ma ’ga’ tsam sñan pa (6)lags || khyod kyi gsuṅ don grub
pas kyaṅ | | thams cad legs gsuṅs kho na lags |

| khyod kyi gsuṅ ni rnam brtags na | | gaṅ źig ’jam daṅ rtsub pa daṅ || gaṅ yaṅ de gñis ldan
pa dag | | thams cad ro gcig ñid du ’gyur |

| e ma’o śin tu yoṅs dag pa’i | | phrin (7)las rnams kyaṅ rab tu bzo || de yis rin chen gsuṅ
rnams kyi | | snod ’di ’dra ba ’di bgyis so |

| khyod źal blta na rab sdug pa | | de las mñan na sñan pa yi || gsuṅ ’di dag ni zla ba las
| | bdud rtsi ’dzag pa bźin du gda’ |

| khyod kyi gsuṅ ni ’dod chags kyi | | rdul (113a1)rab źi mdzad char sprin ’dra || źe sdaṅ sprul
ni gdon pa’i phyir | | nam mkha’ ldiṅ daṅ ’dra ba lags |

| yaṅ daṅ yaṅ du mi śes pa’i | | rab rib ’joms pas gdugs daṅ ’dra || ṅa rgyal ri bo mṅon ’joms
pas | | brgya byin mtshon cha ’dra ba lags |

| (2)don gzigs pas ni mi slu ba | | noṅs mi mṅa’ phyir rjes su mthun || legs par sbyar bas ge
sla ste | | khyod kyi gsuṅ ni legs gsum ldan |

| re źig daṅ por khyod kyi gsuṅ | | ñan pa rnams kyi yid ’phrog mdzad || de nas yid la bsam
bgyis na | | rdul daṅ mun pa (3)dag kyaṅ sel |

| phoṅs pa rnams kyi dbugs ’byin ciṅ | | bag med rnams ni skrag par mdzad || bde ba can dag
skyo bgyid pas | | khyod gsuṅ kun daṅ ’tsham par ’jug |

| mkhas pa rnams kyi dga’ ba skyed | | bar ma rnams kyi blo yaṅ spel || tha ma’i rab rib rnam
’joms (4)pas | | gsuṅ ’di skye bo kun la sman |

| lta ba dag las dgar mdzad ciṅ | | mya ṅan ’das par ñe bar ’dren || ñes pa sel mdzad khyod
kyi gsuṅ | | yon tan rnams kyi char yaṅ ’bebs |

| kun la ma thogs thugs mṅa’ źiṅ | | dgoṅs pa’aṅ kun du ñer gnas pas || (5)de slad khyod kyis
luṅ bstan kun | | thams cad la yaṅ slu mi mṅa’ |

| gaṅ slad yul min dus min daṅ | | snod min rnams su mi ’jug pa || de slad khyod gsuṅ don mchis
te | | brtson ’grus legs par brtsams pa bźin |

| gsuṅ la bstod pa ste le’u bdun pa’o ||

## Chapter 8: Śāsanastavaḥ

|| (6)bgrod pa gcig daṅ thabs bde daṅ | | legs par ’brel daṅ ñes pa med || thog ma bar daṅ mthar
dge bas | | khyod kyi bstan ’dra gźan la med |

| khyod kyi gźuṅ lugs de lta bu | | gcig pu phaṅs la lta chags pas || byis pa gal te smod bgyid
nas | | lta daṅ ’dra ba’i (7)dgra ma mchis |

| gźan ni ’gro ba’i don slad du | | sdug bsṅal maṅ bstar gaṅ lags pa || de bsams khyod bstan
ṅan na yaṅ | | gnas par bgyi ba la thug na |

| phan pa gsuṅ źiṅ phan mdzad pa | | khyod kyi bstan pa ci smos te || mgo la źugs ni ’bar bas
kyaṅ | | ci yi (113b1)slad du sgrub mi bgyid |

| khyod kyi bstan pas raṅ dbaṅ daṅ | | byaṅ chub bde daṅ źi ba daṅ || khyod kyi yon tan bsṅags
pa daṅ | | legs pa bźi po ’di kun thob |

| dpa’ bo khyod kyi bstan pa ’di | | mu stegs thams cad skrag mdzad la || bdud ni sems khoṅ
chud mdzad ciṅ | | (2)lha daṅ mi rnams dbugs kyaṅ ’byin |

| ’chi bdag bstan pa khams gsum gyi | | sa chen dag na spyod bgyid pa || mi thogs bzlog pa ma
mchis pa’aṅ | | khyod kyi bstan pas zil gyis mnan |

| khyod kyi bstan pa’i lugs ’tshal ba | | dga’ na bskal par yaṅ gnas la || gaṅ du (3)bdud kyis
mi rdzi ba | | der yaṅ dga’ mgur rab tu mchi |

| luṅ gi don ni bsam pa daṅ | | bsgom daṅ gus par mñan pa yi || dus gsum cha dbye khyod kyi
ni | | bstan las gźan la mchis ma lags |

| draṅ sroṅ skyes mchog khyod kyi bstan | | de ltar legs pas khyab ’di la || ma (4)gus gaṅ lags
de las ni | | sdug bsṅal chen po’aṅ ci źig mchis |

| bstan pa la bstod pa ste le’u brgyad pa’o ||

## Chapter 9: Praṇidhistavaḥ

|| khyod thos pas ni spro ba skye | | mthoṅ bas dad pa skye bar ’gyur || khyod gsuṅ thos pas
dga’ ’gyur te | | bstan pas rnam par grol bar mdzad |

| khyod kyi (5)sras kyis mgu bar ’gyur | | ’phel bas skye dgu rnams kyaṅ dga’ || gśegs pa na
ni phan ’dogs mdzad | | ldog pa na ni rgud par ’gyur |

| bsgrags pas sdig pa ’phrog par mdzad | | khyod dran pas ni raṅs par ’gyur || btsal bas blo
gros skye ’gyur te | | yoṅs su śes pas (6)rnam par ’dag |

| khyod la bsu bas dpal du byed | | bsten pas blo gros mchog tu ’gyur || bsten na ’jigs pa med
par mdzad | | bsñen bkur bgyis pas bde bar ’gyur |

| tshul khrims phun sum tshogs pas dag | | bsam gtan phun sum tshogs pas daṅ || śes rab phun
(7)tshogs mi ’khrugs pas | | khyod ni bsod nams mtsho chen lags |

| khyod sku bltar ’os rin chen te | | legs gsuṅs mñan ’os rin chen lags || chos ni spyad ’os
rin chen pas | | khyod ni rin chen ’byuṅ gnas lags |

| khyod ni chu bos bdas pa’i gliṅ | | smas pa’i (114a1)bdag ñid skyob pa ste || srid pa’i ’jigs
pas ñen pa’i skyabs | | thar ’tshal rnams kyi ’dren pa lags |

| tshul khrims dag phyir snod kyi mchog | | źiṅ gśin ’bras bu phun sum tshogs || srog chags
kun la phan mdzad phyir | | grogs kyi phul yaṅ (2)khyod lags so |

| phan ’dogs mdzad pas mdza’ bśes te | | ’grogs na bde phyir sñiṅ du sdug || źi phyir gcig tu
yid du ’oṅ | | yon tan kun mṅa’ mchod ’os khyod |

| sdig pa med pas yid daṅ ’thad | | sku gsuṅ bzaṅ bas dga’ bar mdzad || don kun ’grub phyir
(3)dpal yaṅs te | | yon tan legs rten bkra śis lags |

| smon lam la bstod pa ste le’u dgu pa’o ||
